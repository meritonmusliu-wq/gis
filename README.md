# GIS Centro Fresaggio

Website statik për **GIS Centro Fresaggio** — qendër fresimi dentare në Lecce.

## Kërkesat

- [Node.js](https://nodejs.org/) (v18 ose më e re)

## Instalimi

Në folderin e projektit:

```bash
npm install
```

## Nisja

```bash
npm start
```

Pastaj hap në shfletues: [http://localhost:3000](http://localhost:3000)

Për të ndaluar serverin: `Ctrl + C` në terminal.

## Struktura

```
├── index.html      # Faqja kryesore
├── css/style.css   # Stilet
├── js/app.js       # JavaScript
└── images/         # Imazhet
```
